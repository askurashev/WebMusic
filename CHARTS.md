# Личные музыкальные чарты

## Запуск на Windows

Дважды нажмите `start.cmd`: он запускает PHP на `127.0.0.1:8765` и открывает
<http://127.0.0.1:8765/music.htm>. На странице расположены единая библиотека, недельный
чарт и итоги. Плеер постоянно закреплён снизу и доступен при прокрутке.
Старый адрес `charts.htm` перенаправляет на общую страницу.

Открытие `music.htm` через `file://` не работает: браузер не исполняет PHP.
`music.ini` с `root = library` подходит для музыки в `F:\WebMusic\library`.

Нужен PHP 8.1 или новее. Скрипт ищет PHP в PATH, затем `.runtime/php/php.exe`.
В этой рабочей копии уже подготовлен переносимый PHP в `.runtime/php`.
Он не включается в Git. Для другой машины скачайте Windows ZIP с
[официального сайта PHP](https://www.php.net/downloads.php?os=windows) и распакуйте
его в эту папку либо установите PHP в PATH.

Другой вариант запуска: `php -S 127.0.0.1:8765 -t .` из корня проекта.
Скрипт запускает сервер в фоне до завершения процесса или перезагрузки Windows;
повторный запуск использует уже работающий сервер этого проекта.
Журналы находятся в `.runtime/server.out.log` и `.runtime/server.err.log`.
Сервер доступен только на этом компьютере. Редактор использует ту же модель личного
доступа, что и исходный плеер; отдельных аккаунтов пользователей здесь нет.

## Фильтры библиотеки и архив треков

В библиотеке доступны два быстрых фильтра: участие в чарте выбранной недели
(все / добавлены / не добавлены) и архив (все / только архивные / только не в архиве).
Они работают совместно с поиском и выбором плейлиста. Фильтр чарта учитывает
несохранённые изменения. Кнопка добавления всего списка в очередь использует
текущую отфильтрованную подборку.

Кнопка с коробкой рядом с очередью и звездой отправляет трек в архив;
повторное нажатие возвращает его. Отметка сохраняется сразу в
`chart-data/archive.php`, независимо от сохранения недели. Архивирование не
перемещает аудиофайлы и не удаляет песню из чартов или плейлистов.

## Неделя

1. Выберите дату — она приводится к понедельнику этой недели.
2. Перетащите треки из библиотеки в чарт или добавьте их кнопкой ★.
3. Расставьте места перетаскиванием или стрелками. Крестик убирает трек только из чарта.
4. Нажмите иконку экспорта в шапке «Чарт недели» (подсказка «Сохранить чарт и создать папку»). Сохранение истории и копирование файлов —
   отдельные операции: при ошибке копирования сохранённый рейтинг не теряется.
5. Для следующей недели нажмите «Следующая неделя». Новый список копируется из
   последней сохранённой недели перед выбранной датой. Предыдущий снимок остаётся в архиве.

Число композиций не ограничено. Повтор одного и того же файла в одной неделе запрещён.
Для длинной библиотеки есть поиск и постраничное раскрытие по 100 треков.
Прослушивание, добавление и изменение мест работают и без перетаскивания.
Кнопка ▶ запускает композицию в закреплённом плеере, сохраняя его очередь.
`NEW` означает дебют, `ВОЗВРАТ` — появление после перерыва, стрелки показывают изменение
относительно предыдущей календарной недели. Пропущенные недели не засчитываются.

Архив позволяет исправлять прошлые недели. Итоги сразу пересчитываются после сохранения.
При несохранённых изменениях переход к другой неделе требует подтверждения.
Конфликт сохранений из нескольких вкладок отклоняется, чтобы не затереть чужую правку.

## Библиотека, плейлисты и очередь

В библиотеке есть поиск, фильтр по плейлисту и кнопка обновления музыкальной папки.
В строке трека: ▶ — слушать, ＋ — добавить в очередь, ★ — добавить в чарт.
Выпадающий список «В плейлист…» добавляет песню в существующий плейлист или создаёт новый.
Плейлисты сохраняются в `music.pls/*.mfp.json` в штатном формате плеера; плейлисты,
созданные через его настройки, тоже доступны в библиотеке. Повторное добавление
того же трека не создаёт дубликат. Под названием песни показаны теги плейлистов и
формат файла; полный путь доступен при наведении.

«В очередь весь список» добавляет текущий результат фильтрации библиотеки.
«В очередь весь чарт» добавляет композиции выбранной недели в порядке мест.
Штатное правило очереди исключает повторные добавления уже ожидающих воспроизведения треков.
Иконка очереди в нижнем плеере открывает плавающее окно над ним: композиции можно
перетаскивать, двигать стрелками и убирать крестиком. Настройки открываются аналогично.
Окна закрываются крестиком, клавишей Escape или нажатием вне плеера.

## Итоги месяца и года

Используется фиксированная формула личного чарта: **100 / место** за неделю.
Первое место получает 100 баллов, второе 50, третье 33⅓ и т. д.
Баллы складываются за выбранный период без промежуточного округления.
Это явно выбранная методика для неограниченного личного списка, а не попытка
воспроизвести универсальную формулу радиостанций. Длина недельного списка не влияет
на стоимость места. Учитываются и высокие места, и длительность присутствия.

При равенстве суммы последовательно сравниваются число недель (больше лучше),
лучшая позиция, средняя позиция, первый вход в выбранном периоде и путь файла.
В таблице отдельно показываются число недель, лучшая и средняя позиции.
Неделя относится к месяцу и году своего понедельника, включая недели на границе года.
Отсутствующие недели не заполняются автоматически.

## Папка для телефона

`chart-exports/current` содержит **копии исходных аудиофайлов**, не ссылки и не плейлист:

```text
chart-exports/current/
  001 - Исполнитель - Композиция.mp3
  002 - Другая композиция.flac
  ...
```

После сохранения самой новой по дате недели папка обновляется автоматически.
При редактировании старой недели она не меняется. Кнопка «Обновить папку для плеера»
позволяет повторить копирование. Скопируйте `current` на телефон обычным способом.
В телефонном плеере выберите сортировку по имени файла: встроенные теги и номера
треков внутри аудиофайлов не изменяются. Перекодирования нет, формат должен поддерживаться плеером.

Сначала создаётся полная временная копия. Только после успешного копирования она
заменяет `current`. Исходники в библиотеке никогда не удаляются и не переименовываются.
Выбывшие треки исчезают только из `current`. Пустой сохранённый чарт создаёт пустую
подборку. Если исходный файл недоступен или не хватает места, предыдущая выгрузка сохраняется.
На время обновления нужно место для обеих версий подборки.

Не добавляйте свои файлы в `current`: при обнаружении посторонних файлов обновление
останавливается, не удаляя их. Служебный `.mfp-export.json` содержит список файлов,
принадлежащих экспорту. Библиотека не должна включать папку `chart-exports`.

## Данные и проверка

История сохраняется на сервере в `chart-data/history.php` — JSON с защитным PHP-префиксом.
Сделайте резервную копию всей папки `chart-data`, чтобы сохранить историю рейтингов.
Треки идентифицируются относительным путём в библиотеке. Переименованный или перемещённый
файл считается новым треком; старый остаётся в истории и помечается недоступным.

Настройки библиотеки читаются из `music.defaults.ini` и переопределяются через `music.ini`.
Для чартов не требуется отдельная база данных или Node.js. Новые файлы интерфейса:
`charts.css`, `charts.js`, `charts.php`, `music.layout.css`, `music.playlists.php`. Разметка чарта находится в шаблоне внутри
`music.htm`; Shadow DOM изолирует стили и идентификаторы от штатного интерфейса.

Серверные интеграционные проверки: `php tests/charts-test.php`.
Они запускают отдельный сервер и временную библиотеку, не затрагивая пользовательские данные.

Проверки интерфейса без браузера: `node tests/charts-ui-test.mjs` и `node tests/player-ui-test.mjs` (Node нужен только
для разработки). Зависимость теста: сохраните
<https://unpkg.com/linkedom@0.18.12/worker.js> как `.runtime/linkedom.mjs`.
